# rplaceRT Quest Android source snapshot

This folder contains the Android app source, native source for its five bundled emulator cores, and build configuration. Open the folder in Android Studio or build with a compatible Android SDK/NDK, CMake, and Gradle installation.

The large generated r/place playback datasets and generated rumble profile assets are omitted to keep this source upload manageable. The app's source code and the scripts/data inputs used to regenerate rumble assets are included where available. This snapshot does not contain signing keys or machine-specific Gradle configuration.
